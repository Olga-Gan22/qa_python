# qa_python

# Библиотека книг (Books Collector)
## Список реализованных тестов

### Тесты для добавления книг (`add_new_book`)

1. **`test_add_new_book_add_two_books`**  
   Проверяет, что можно успешно добавить две книги и их количество в коллекции будет равно 2.
2. **`test_add_new_book_invalid_name_not_added`**  
   Убеждается, что книга с некорректным названием (пустая строка или длиннее 40 символов) **не добавляется** в коллекцию — словарь остаётся неизменным.
3. **`test_add_new_book_only_spaces_added_with_empty_genre`**  
   Проверяет поведение при добавлении книги с названием, состоящим только из пробелов:
   * книга **добавляется** в коллекцию (ключ с пробелами присутствует в словаре);
   * у книги по умолчанию устанавливается **пустой жанр** (`''`).

### Тесты для работы с жанрами

4. **`test_set_and_get_book_genre`**  
   Проверяет установку и получение жанра для книги (на примере нескольких пар «книга–жанр»).
5. **`test_get_book_genre_nonexistent_book_returns_none`**  
   Гарантирует, что для несуществующей книги метод `get_book_genre` возвращает `None`.
6. **`test_get_books_with_specific_genre`**  
   Проверяет корректность поиска книг заданного жанра.
7. **`test_get_books_with_specific_genre_invalid_genre_returns_empty_list`**  
   Убеждается, что для несуществующего жанра метод возвращает пустой список.
8. **`test_get_books_for_children_only_safe_genres`**  
   Проверяет фильтрацию книг для детей: в результате отсутствуют книги жанров «Ужасы» и «Детективы».


### Тесты для управления избранным

9. **`test_add_and_get_favorites_books`**  
   Проверяет добавление книг в избранное и получение полного списка избранного (на разных наборах книг).
10. **`test_delete_book_from_favorites`**  
    Убеждается, что удаление книги из избранного работает корректно.
11. **`test_add_existing_book_to_favorites_ignores_duplicate`**  
    Проверяет, что дублирующая запись книги в избранном не создаётся (количество вхождений остаётся равным 1).

### Дополнительные тесты

12. **`test_new_book_has_no_genre`**  
    Гарантирует, что у вновь добавленной книги жанр по умолчанию — пустая строка (`''`).
